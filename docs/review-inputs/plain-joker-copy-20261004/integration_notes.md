## 4. 状态要说清“还没发生”

保留判定语义，换玩家用语，并先看是否拥有此牌：

1. 未购买： “尚未购买，买入后才会生效”。不要展示“静态仍有效”、现有成长或“已触发”。起始倍数可明确标成“初始”。
2. 未选牌： “选好牌后判断”。只依赖已知公共资源的失败条件可以说“现在金币不足”等；不得推断牌型或未来随机结果。
3. 已选牌且满足： “这手符合条件”。不是“本手已触发”。对于受额外次数总上限约束的牌，也不能在未结算时声称额外计分已执行。
4. 未满足： “这手不符合条件”，可附已有权威判定得出的简短原因。
5. 事件型：按种类说“过关时检查”“成功弃牌后获得”“购买成功后增加”“出牌结算后才更新”。不要笼统说“事件时检查”。
6. f08：出牌前“出牌时揭晓，每手抽一次”；结算后用实际记录写“本手抽中”或“本手没抽中”。计分封禁时写停用，不能继续说等待抽取。
7. 成长牌：分开“当前每手加成 +X”和“满足条件后，下手再增加”。当前成长不能写成这手才获得的奖励。
8. 计分封禁： “本场计分加成暂停”。只暂停其计分与版次，成长、资源、经济或静态效果按原规则保留；不得把整牌所有能力都改成失效。
9. a07商店：显示“下场还可赚2次（进场重置）”，不能拿上一场计数冒充下场已用次数。
10. e10：未买时不显示已累计过关数；拥有时只读保存的0/1进度，不从历史重算。

对于多条能力的牌，最好按效果分开短状态。例如 a05 “当前每手 +12 热度；只出1张后还会成长”，不能只用一个“条件满足”把当前收益与未来成长混起来。

## 5. 只需解释一次的玩家词汇

可放在现有折叠细则内，按相关牌引用：

- “能计分的牌”：组成这手牌型的计分牌，而且没有被停用。普通点数被压到0，不等于整张牌被停用。
- “附带牌”：和本手一起打出，但没被选作这个牌型的计分牌。它仍算“打出了几张”，也可能帮同点数条件凑张数。
- “留在手里的牌”：这手没有打出的牌，不包括之后补抽的牌。
- “再计分”：这张扑克牌的点数、增强、版次、逐张加成都再算；不会重复角色或整手加成，且不能不断自己接自己。
- “倍率 +X”与“倍率 ×X”必须保留不同符号。增加热度不是最终得分直接增加同样数值。
- 大丑牌是持有后按条件自动起效，不需要把它像手里的扑克牌一样打出去。
