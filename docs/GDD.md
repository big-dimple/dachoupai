# 《大丑牌》核心策划

## 定位

“扑克构筑 + 荒诞舞台演出”的 H5 Roguelike。规则几分钟学会，核心乐趣来自角色身份、大丑牌构筑、连续触发和夸张的声音/数字反馈。

## 六大丑：玩家的第一层身份

角色不是头像皮肤，而是每局构筑的第一条规则。首版六名角色：

1. **默剧王·阿默** — 「独角戏」：只打 1 张牌时，倍率 ×3。偏极端小牌玩法。
2. **赌命客·骰爷** — 「再来一把」：每次出牌进行一次确定性 Seed 随机判定，可能 ×2，也可能 ×0.75。高波动。
3. **空袖·老幻** — 「袖里有牌」：顺子、同花、同花顺额外 +120 基础热度。偏五张成型。
4. **捧哏王·二响** — 「接得漂亮」：对子、两对、三条的倍率 +1.5。偏对子体系。
5. **热场王·阿燥** — 「换个活儿」：本次牌型与上次不同，倍率 +1。鼓励不断换牌型。
6. **压轴·谢幕人** — 「最后一个包袱」：本场最后一次出牌，最终倍率 ×2。偏资源规划。

### 角色体验原则

- 选择界面直接说人话，3 秒内看懂角色怎么玩。
- 角色拥有自己的称号、色调、舞台台词和音色，但不依赖复杂剧情。
- 被动必须真实改变构筑选择，禁止只做无感的 +5%。
- 后续允许角色成长/解锁，但第一版不做账号和养成系统。

## 单场流程

角色选择 → 入场 → 发 8 张 → 选择 1–5 张 → 出牌 → 识别牌型 → 角色能力结算 → 连锁演出 → 累计热度 → 达标或耗尽手数。

## 计分

最终热度 = （牌型基础热度 + 角色基础热度加成）×（基础倍率 + 角色倍率加成）× 角色最终倍率。

所有来源必须可解释，演出层只能展示结果，不能偷偷修改规则结果。
