# 苏轼“贬谪”：当手强爆发提案

**以用户16:05玩法与16:08文案指令为准，只提案待确认，产品未实现。** 原整对改牌、封存占位和封掉熟路方案全部撤回，不保留为推荐；单张×1.25也仍未采纳。

**贬谪**

> 出牌时，舍弃手里剩下的牌，这一手得分变为4倍。每场限用1次。

唯一直接代价就是这批实际舍弃的牌。无需同点副组，普通对子也能发动；舍弃牌进普通弃牌堆，不参与本手计分、不永久删牌。确认出牌时舍弃与爆发一起生效，预览或取消不消耗。至少有一张未出的牌才可发动。

**同花例**：八张为 `♥2 ♥5 ♥8 ♥J ♥K ♠9 ♣9 ♣3`。打五张红桃，同时舍弃 `♠9 ♣9 ♣3`；裸牌Lv1、无其他效果时，原本700分，当手直接变为 **2800分**。没有之后才能兑现的条件。若打普通对子，也同样是舍弃其余六张、当手得分×4。

结算后按正常流程补牌，不少补牌、不降手牌上限，不额外扣弃牌次数、出牌次数或金币。没有封存、占位、延时惩罚或隐藏削弱。玩家的选择只有：**这一手是否值得把剩余手牌全舍掉，立即打出爆发。**

×4、每场1次是易调整的提案初值，待用户确认；不是已经校准通过的数值。此案替换旧助攻，不与旧×2／×4叠加。苏轼以舍牌换当手爆发，与花蕊的金币、文成的积层、秦琼的押型、辛弃疾的补牌、刘娥的单牌搬点区分。

可见说明只写舍弃什么、得分增加多少、何时生效；不造新技能词。本案不添加诗句；若后续加点缀，必须核对原作出处并与机制说明分开。
