# 苏轼“贬谪”：一页玩法提案

**15:50主题已明确，具体玩法待讨论；只提案，不实现。单张×1.25仍未采纳。** 以下两案都以替换旧副组倍率为前提，不与原×2／×4叠加，技能名可先直叫“贬谪”。

取的是“失去眼前优势，仍把手中材料重新组织成作品”的意象。《寒食帖》的原作与馆方释读呈现生活困乏、仕途挫折与创作，不是遭难就自动快乐或变强。玩家主动选择的是应对取舍；规则是游戏虚构，不叙述苏轼自愿被贬。[原作与馆方说明](https://theme.npm.edu.tw/exh106/npm_anime/ColdFoodObservance/ch/index.html)

## 主推荐：交出一副对子，补一个缺口

**人话说明：选一对牌，一张本场不能用了，另一张帮你补成想打的牌型。**

- **怎么选**：每场一次，选手里一整对，明确哪张封存、哪张补缺。补缺牌可以临时改“点数”或“花色”之一，不能同时改两项。玩家从当前八张里重组这次主手，不抽牌、不看新候选；确认出牌前可取消。
- **真代价**：封存牌占着一个手牌位置，直到本场结束，不能打、不能弃，也不触发留手收益；有效可用手牌因此少一张。补缺牌本次只帮助成型，不贡献普通点数或自身单卡计分效果。原来那副对子也没了。
- **怎么回报**：只在这次出牌改写，随后恢复原卡属性；按实际新牌型正常计分，**不白送乘倍率**。必须实际使用补缺牌参与成型。后续仍按普通出牌补回手牌上限，封存位继续占用，没有额外补牌步骤。
- **节奏**：同一次出牌内完成“舍掉对子→补成新手→结算”；之后承担少一个可用手位的余波。没有先打几手攒层，也没有失败赔付或随机猜约。

**同花例**：八张为 `♥2 ♥5 ♥8 ♥J ♠9 ♣9 ♦K ♣3`。原来只有四张红桃和一对9。选整对9，封存`♠9`，让`♣9`本次按`♥9`成型，配四张红桃打出同花；这张9不加普通点数。玩家交出的不是废牌，而是一副现成对子和一个后续手位。

**顺子例**：`♠4 ♥5 ♦7 ♣8 ♠Q ♥Q ♣2 ♦K`。封存`♠Q`，另一张`♥Q`本次改作`♥6`，与4、5、7、8组成顺子。不等抽到6，也不靠额外手牌；能否用现有一对修好缺口，由玩家自己发现。普通对子路线也可用同样方法把两对中的一对交出去，补成另一点数的三条。

**为什么优先做它**：损失与新机会都落在眼前的真实牌上。不是“受罚领倍率”，而是把现成优势拆开，换一种写法。新玩家能看懂一次变局，熟练后会判断何时不该牺牲对子、该改哪种属性。代价在一手清场时可能偏轻，增强牌与Boss边界也未定；方向获认可后再小范围校准，不能凭这两例宣称平衡通过。

## 备选：封掉熟路，把原来的本领带去另一种牌型

每场一次，从当前八张中选两种**已经能打出来、且分属不同路线族**的主手。主动封掉其中一种，本场不能再打；另一种在本场暂用被封牌型的“基础热度与基础倍率”。只搬基础，不搬旧手普通点数、Joker或路线成长；不积层、不加倍率、不预测未来。两种牌型都已在手，确认改路时就能打出新路；只在本场有效。

**例**：`♥2 ♥5 ♥8 ♥J ♥K ♠9 ♣9 ♣3`，同花和对子都已现成。玩家放弃本来能直接打的同花，封它到本场结束，让普通对子暂借同花的基础值。裸牌Lv1时，当前同花可得700；改路后的对子为`(140+18)×4=632`，不是两份叠加。眼前少拿68分，还失去本场同花打法，换来后续普通对子也能承接原来基础的选择。之后若另组牌，仍须自己正常做牌，没有送牌。

这个方向把“离开原有位置，但本领可以另寻出路”做成规则，代价是放弃熟路；不过它需要先握有一手好牌，更偏中后期转线，也可能将打法压向低张数对子，因此只作备选。它与文成的区别是迁移一套已存在的基础，不靠出牌次数增长层数；与秦琼的区别是当下两手都已可见，没有猜中才兑现。

**建议先讨论主方案。** 刘娥是指定单牌搬点，文成是积层释放，花蕊是花钱换倍率，秦琼是押型，辛弃疾是补牌选择；这里是用一整对承受贬损，改写已知手牌的结构。旧成组不必保留原样，但“主动取舍、逆境创造”应成为苏轼的操作辨识。主题已定，待确认的是是否接受这个“整对换缺口”的玩法骨架；未授权实现或再开大模拟。

牌例只用正式`evaluateR2Hand`核对原有牌型与改写后的成型：前两副原手只可成高牌／对子，改写后分别为同花／顺子；第三副两种主手均成立。不是新规则运行、浏览器实测或强度验收。
