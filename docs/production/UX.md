## 1. 不把桌面缩小当手机适配

竖屏以可用宽度 360–430 CSS px 为首要布局；桌面以 1280×720 以上为目标，同时测试 1024×768；横屏手机至少测 844×390，平板测 768×1024。320px 窄屏提供同一套可滚动详情/紧凑布局或明确支持提示，不偷偷把正文缩成几像素。

竖屏分区：顶部局/目标/资源（约 12% 高）→Joker 槽与展开入口（约 16%）→中央计分与选牌预览（约 25%）→可操作手牌（约 30%）→固定操作栏（余下，含安全区）。百分比只是排布起点，最小点击与文字尺寸优先，空间不足折叠低频信息，不缩小出牌按钮。

桌面采用侧边局信息、上方构筑区、中央得分、下方手牌与操作；不要把标题、SEED 和全角色台词占据关键空间。SEED/版本放设置或局详情，开发调试信息不成为正式 HUD。

主操作命中区至少 48×48 CSS px，次操作至少 44×44；高频正文至少 14px，主要数值 22px 以上。手牌允许重叠，但每张至少有 36px 宽独立可点击露出区域，并提供抬起与描边状态；窄屏允许水平卡带和稳定聚焦，不做两行随机换位。

使用纯函数 layout(viewport,safeInsets,mode) 返回各区域和命中框，再由 Phaser 渲染。resize 改视图，不重建本局；DPR 只改变清晰度预算，不改变 CSS 点击面积。方向切换、浏览器地址栏伸缩后选择与确认状态保留。

D16增加真实浏览器栏占高的390×740、360×640与844×300检查，高DPR触摸不能用一倍像素画布放大代替。菜单开关使用同一固定触发按钮，保留未提交选牌；旁边提供真实全屏/退出入口。自动横屏与隐藏浏览器栏仅是浏览器请求，未获允许必须如实提示并保留操作，尺寸仿真通过不算Android实机通过。

## 4. 结算节奏

一次手牌只允许一个主焦点：出牌落位→牌型与点数→计分牌逐张→角色→Joker 链→总分入账。H、M、最终分三处数字对应 trace 的真实变化。+倍率与×倍率有不同符号与声音，不在没有触发时让整排牌一起亮。

按D22调整D18过慢的节拍：选择反馈首帧仍以80ms为目标；默认1×逐事件演出，不按整手长度压缩、不折叠计分重触发。每条计算仍经过来源预备、飞入、数字命中、余韵；普通扑克从约0.5秒逐步加速至约0.3秒，角色约0.6–0.8秒，加倍率约0.4–0.6秒，乘倍率保留约0.9–1.1秒蓄力/命中停顿。事件越多节奏渐进，但每个来源保持可辨识的下限；重触发仍逐次高光，不合并数字。来源越多整手自然更长，2×/4×和快进由玩家选择。以上是设计目标，实际时长与目标设备实测单列。

速度 1×/2×/4× 可切换且持久化；加速只改变播放映射。支持按住/按钮快进当前手，结算日志仍完整。结算中误点出牌不能排队自动打下一手。按退出先确认，再以已确定结果保存并结束动画。

## 5. 音频

应用内部保留Master/Music/SFX/UI总线；P06按D19只向玩家提供“背景音量”“音效音量”两条0–100%滑杆，0即关闭。D43首次默认背景30%、音效80%，UI跟随音效；已有两路音量原值保留，v1旧总量仍按原22%/100%折入两路；不再显示静音、关闭背景音乐或总音量控件。独立持久化两路数值，旧静音迁移为可见0%、旧总量折入两路，避免隐藏开关让滑杆失效。首次用户手势解锁，播放失败不阻断命令；后台暂停，回来恢复同一音乐实例。

最低声集：选择/取消、无效操作、出牌、弃牌、点数累加、+倍率、×倍率、重触发、购买/出售、刷新、成功、失败、稀有揭示。连锁音高按事件层级有限上升，设上限与动态范围，不能 20 次触发后刺耳爆音。低音量下仍能区分阶段，静音时靠视觉完全可理解。

P06依用户最新要求替换P05肖邦自制改编为有可核对来源的舒伯特小夜曲D957/4钢琴音轨。保留完整主旋律、原调和录音节奏，跨场连续，首手势按需加载；不叠加自制鼓点/旋律或变速变调，不用竞品音轨。Stem Music不在当前范围。

逐来源数字滚动对应有界颗粒/咕噜声；热度、倍率、总分不同音色，加乘力度不同。弃牌为降落滑声、出牌为上扬滑声、购买为金币与纸牌，稀有揭示多一层短泛音；只有实际事件触发。滚声不逐帧创建音源，与1×/2×/4×演出真实持续时间对应；取消、快进、后台及音效0及时清理，音乐音量不改变SFX力度。

按D43最新反馈，当前显示的本手H×M加此前累计达到目标即燃小火，达到两倍目标燃大火，五倍目标进入极高档；完整出牌以已保存的实际得分收尾，刚好达标也不能漏火。低沉暖风声随三档改变，补一次有界起燃，保留可辨识中频而不使用刺耳噼啪主声。每次临时演出身份只消费一次起燃，重绘不叠音；回看只重演视觉/来源，不再起燃或播通关终结声。连续底火与不等距、不同宽高焰峰保持层次，数字由安静水平中段和上层文字保护，不能切成等距四簇。不因最后一个计分事件自动点火，不预读最终分；火焰的热流/暖芯/余烬避开数字窗口，不遮文字、手牌、按钮。加热度、加倍率、乘倍率、重触发、失效提示音色不同，只有真实来源参与。减少动态保留静态超目标标记，取消/后台/音效量为0停火声；火焰不代表提前入账或未来押注成功。 D28的大火沿四周外框展开缓存热流、暖芯和余烬，窄安全带避开扑克角标与操作文字；小火仍仅计分框。新一次保存成功的失败有短促温暖收尾声，恢复、回看和重绘不重复，静音/后台不排队补播。

## 6. 教程与复盘

教学给固定可复现的局部手牌，步骤只指向当前必要动作；用户实际完成才消失，不用时间延迟假装学会。读过扑克牌的人可直接跳过；没读过的人能在详情看例子。完整图鉴可查牌型计分集合，不只列扑克大小。

失败页给：差额、最后几手得分、主要来源、资源余量、当前构筑；提供回看最后一手、同 seed 重试、新 seed 新局。提示来自可解释的实际数据，例如“还有 2 次弃牌未使用”，不编造“只差运气”。胜利页给有效成长/流派摘要与继续无尽，不把所有统计密密麻麻堆首屏。
