# 苏轼平衡评估：副组门槛与有效收益

状态：**待规则决策，仅离线评估，未修改产品**。范围只含苏轼；P08 保持 in_progress，不推导六英雄整体平衡或通关率。

建议单一方向：**增加“单张同点回声 ×1.25”低档，保留现有副对子 ×2／副三条 ×4、合格主手与每场一次。** 它直接改善同花、顺子占用五张后难凑副组的问题，同时不再放大已有同点成型牌组的 ×4 上限。代价是新增一档判断与展示、额外消耗一张副牌，并可能提前用掉本场大倍率机会；**普通对子主手仍不合格**。本结论是下一步规则提案，不是已获准实施的数值。

## 样本与真实规则

基线 main `c8f86be235a8d453fa2260a88434c852d493ca05`；实际模拟源码 `583c48a94dbd91bfa5f46ae580240046016ab9cc`，运行时工作区干净。完整结果：[report.json](evidence/sushi-balance-assessment-2026-10-17/report.json)。

- **自然发牌**：16,384 个固定种子 `sushi-balance/natural/<0..16383>`，每个均由正式 `createRun`、当前新局身份、`LeaveShop`、`EnterStage` 得到第一场八张手牌。标准难度0、程序事件关闭、无购买／增强／版本牌、无 Boss。未改手牌、牌库、资源或 RNG。
- **可选主手**：对每副相同的八张牌穷举全部218种一至五张主手，调用正式 `evaluateR2Hand`；分别找同花族 F、顺子族 S、严格普通对子 P、同点族 G、全部 ANY 的最佳方案。它是可见牌的理想选择上界，不是玩家操作记录。G 包含对子、两对、三条、葫芦、四条等；P 只含普通对子。
- **已有做牌敏感性**：三类预设牌库各2,048副八张牌，每副分别按对应族 Lv1、Lv5计算。仅分析假设已完成的牌组；不声称这些改造能在某关、某金币预算内取得。Lv5统一提升该族各牌型，也不是玩家真实训练分配。
- **弃牌**：另1,024个正式自然新局种子，分别沿 F／S／P／G 可见牌策略最多弃三次，均执行正式 `DiscardHand`。同一条路线的各候选共用抽牌顺序与检查点，不看未来牌。不是最优弃牌搜索，也没有模拟整局胜负。

当前规则取自 [r2Assist](../../src/domain/r2Assist.ts)、[助攻合同](../../src/domain/r2AssistIdentity.ts)、[正式计分器](../../src/domain/scoreR2.ts)、[路线族](../../src/domain/r2RouteGrowth.ts)：高牌、普通对子不合格；其余现有合格主手之外，另取不重叠、未计分失效的同点2张或3张，分别整手 ×2／×4。**副组只要求自身同点，不要求与主牌同点**；主副一同用掉，每场一次。失效牌仍可参与主手成型，但不能充作副牌。这里评估的是能力尚未使用时的机会。

## 三种最小候选

|候选|本次模型的精确定义|辨识与代价|
|---|---|---|
|A 放宽主手|额外允许普通对子主手；副2张 ×2／副3张 ×4不变|对子主路可发动，仍需同点副组；会鼓励将两对拆成“对子主手＋对子副组”，但同花／顺子门槛完全不变|
|B 单张回声|保留当前合格主手。**对这一主手**找不到副对子／副三条时，可消耗1张未失效副牌；其点数须与主手牌型核心之一相同，整手 ×1.25。已有副组仍用原档|保留主副分工和凑大副组的收益；新增的弱档更常见。核心按正式 scoringIds 分类，失效牌仍成型；副牌必须未失效。仍不允许普通对子主手|
|C 蓄力爆发上界|主副资格不变；假设此前两次未助攻出牌各积一层，每层让本次助攻倍率再加25%，满层相当于原 ×2→×3、×4→×6|要新增跨出牌的层数与生命周期，且与文成蓄力辨识接近。本次只算**满层收益天花板**，没有获得两次准备出牌，不能当成实际可用强度|

以上都没有进入规则、内容 hash、存档或场景。B 的 ×1.25 是本次预先固定的比较值，未扫参寻找好看的结果。B08／挑战禁能力、每场一次等全局门仍应保留，不能因新档绕过；本次普通场模型不声称已验收这些未来实现。

纯对子不能发动是资格规则；允许转成同点族主手后机会仍有限，不能将两者统称“对子路线已经可用”。只放开普通对子解决的是 A 那一列，不能解释为同时修好了同花与顺子。

另对**固定指定的五张、五种点数主手**，将标准52张牌的其余47张任选3张全部枚举。指定普通同花与指定普通顺子各有16,215种余牌，正式助攻校验均得到：当前2,761种可用（17.03%），其中副三条仅37种（0.23%）；B 为12,631种（77.90%）。这是固定主手的精确结构说明，**不是任意八张可换主手的概率**，不能和上表混用。

## 有效收益：不能只报倍率

每副牌先找同一路线最佳不助攻分数，再与可选助攻比较；不划算时保留普通出牌。下表是每副牌相对增幅的算术均值，含该路线无法助攻的0增益；不是累积总分比，也没给额外耗牌定价。计算保留正式牌型基础值、等级步进、核心普通点数和最终向下取整；当前方案再与正式 `scoreR2Hand` 差分核对。

|样本／比较范围|当前平均有效增幅|A|B|C 满层天花板|
|---|---:|---:|---:|---:|
|有同花族主手的1,103副|+21.46%|+21.46%|+36.51%|+42.80%|
|有顺子族主手的1,593副|+24.66%|+24.66%|+35.22%|+48.70%|
|有同点族主手的14,499副|+7.71%|+12.46%|+7.73%|+15.45%|
|全部16,384副，比较同手最佳普通出牌|+10.36%|+14.20%|+12.30%|+20.75%|

全样本中，当前虽然2,570副有合法助攻，实际胜过最佳普通出牌仅1,705副（10.41%）；A 为6,461副（39.43%），B 为2,962副（18.08%），C 满层也仅1,706副（10.41%）。例如有三条和对子时，拆主副可能输给直接打葫芦；有同花顺时，切成弱同花来凑副组也可能亏。C 大幅提高少数已有好机会的数字，基本没增加“值得发动”的手牌数量。

B 相对当前的全样本平均有效增幅只多 **1.94个百分点**，同花、顺子可发动频率却明显增加；这符合“补低档使用机会”的目标。其新增档只 ×1.25，不能把81.41%说成同花常态都能 ×2。当前同花助攻平均额外消耗2.01张、副组三条极少；B 选出的同花方案平均额外消耗1.26张（混合各档），总用牌约6.26张，当前约7.01张。

这是裸牌的单次出牌潜力，没有计入留手增强、Joker联动、下一手抽牌质量、每场一次的未来机会成本。**B 的低档若抢先用掉本场次数，可能放弃后续 ×4；不得自动代玩家使用。** 同点族自然样本 B 几乎没有新增有效收益，也不能承诺其解决纯对子需求。

## 决策与后续边界

选择 **B 单张同点回声** 作为唯一推荐方向。它让五张主手剩余三张里更常有一个可做的决定，又不把 ×2／×4改成无条件奖励。A 对纯对子更友好，但未触及这次同花／顺子难发动的主要反馈，且容易将角色路线压成拆对子；C 提峰值却不修机会，新增状态和两次准备成本更重。

待决策明确：是否接受普通对子继续排除、一次弱档仍占本场次数、单张倍率1.25，以及“同点核心”按正式 scoringIds 的分类口径。若产品目标要求普通对子也普适可用，B 单独不能满足，不能在实现时悄悄加入 A。没有获得规则决策前，不改产品。批准后只在苏轼领域合同与对应展示内实施，并覆盖失效副牌、主副重叠、B08／挑战禁用、次数、取消、保存失败／duplicate、真实计分落点；不能由本次分析解锁全局经济或旧档迁移。
