## 三层披露

L0：根 AGENTS、handoff、当前任务条目。L1：与任务直接相关的合同小节。L2：完整内容表、审查快照、历史、测试证据。禁止把全部历史与所有素材清单加入每次必读。

`plan.json` 只负责 ID、依赖、状态、读取路径和证据指针；`WORK_PACKAGES.md` 只负责范围/步骤/验收；设计文档负责规则。不得在三个地方复制并各自改同一组数值。
