# Dark Things Loop — 过渡背景音乐

作者 iamoneabe；作者于OpenGameArt明确标注CC0／Public Domain。来源：https://opengameart.org/content/dark-things-loop ，许可：https://creativecommons.org/publicdomain/zero/1.0/ 。原MP3字节保持，大小/SHA/下载来源见source.json。

此曲用于关闭旧BGM撤下后的音乐空档，不是《怪奇物语》原曲，不声称用户已认可听感。30%音乐与80%音效默认合同保持，首个真实输入解锁，场景切换续播，音乐独立静音/后台暂停恢复。浏览器和实际输出验证另见本包证据。
