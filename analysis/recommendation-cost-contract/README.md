## 建议父锁定的最小口径

1. **当前星数表示新牌机制的条件评级，不能表示指定交易净补强。** 推荐输入使用指定出售后的真实保留状态；交易可执行性、真钱、成长/版次损失和保留牌联动另列事实。满槽未选对象不捏造余额；出售失败不继续假设买入。禁止用类型缺口、理论峰值或每局星数配额补五星。
2. **证据能否定一笔替换，却不能自动给全局净收益星级。** 同输入固定牌面若更差，足以反驳“此牌高星所以换入必更强”；不能将该牌面外推所有未来抽牌。保留已知成本，不由测试分数差直接生成产品星级或隐藏抽牌预测。
