## 有界滞后自适应 A1：可执行反例与暂不采用的原因

实现候选只用于离线对照：以现行D0章暖场F_c作基线、倍率m初始1，上限64。c章结算后读取该章末**公开库存**能力C_c，用 `desired=clamp(0.7*C_c/F_c,1,64)`；`m_(c+1)=clamp(desired,0.8*m_c,1.25*m_c)`；下一章准备商店前公示并锁定三目标 `ceil(F_(c+1)*stageRatio*m_(c+1))`。代码按万分位整数取整，报告用现行每场已ceil目标再乘万分位，保守至多出现额外1整数的二次ceil差；产品落地需选定这一口径，不得混算。所有参数均为实验候选，不是现行规则。

可选防压分记忆是最近三个章末**公开能力**的最大值，绝非历史最高分。`capacityHighWater`单独报告，不悄悄并入基本A1。模型中两手相同成熟牌的曲线只用于上限/响应灵敏度，另有实际公开牌组抽样估计，两者不能混称自然模型。

| 问题 | 可执行约束/结果 | 仍然的代价 |
|---|---|---|
| 故意打小牌、拖手、藏主动、单手爆分 | 估计器无实际得分参数，不读存档RNG/抽牌堆；峰值不能进入m；输入只读 | 不防卖牌/毁牌/留低等级改变公开库存 |
| 先卖强牌压低快照，再买回 | 近3快照高水位抵抗短期下降，倍率每章至多降20% | 真损失也要等3快照；可长期压能力、付卖买成本绕过，不能声称完全防作弊 |
| 巨峰后追赶 | 第8→13章最多1→3.0516，暖场38,877,992 | 追不上GF/SF；把上调改到每章≥2.25/2.51才追得上相对斜率，明显吞成长 |
| 永久损失 | 测试C从1亿骤降100万：3.5倍保持两次，随后2.8→2.24→1.792 | 即使宽松下调，接下来几章仍按已失去的能力收费 |
| 成功经营升级 | 下一章预告前才调整，本章不变 | 玩家可能感到升级白买；必须真人判断，测试不能代签 |

因此**固定F1优先，A1只作比较实验，不建议默认启用**。可选玩家手动升档仍是公开选择，不能包装成自动能力识别准确。

## 能力估计：已经执行的模型与限制

`estimateCapacity`使用公开牌组、公开Joker/成长/等级/现金/资历与实际手数上限；不用run seed、已知下张牌或实际成绩。固定12组独立shuffle，对每组九张手牌枚举所有五张选法，用当前预览的最低随机分支贪心选手；最多两次出牌，打出的牌从本探针删除，补剩余牌，**不放回、不借无限弃牌、不长新资历/实例成长、不领奖励**。不足五张停止。输出12个总分中索引floor((12−1)/4)=2的顺序统计量作为保守候选C，不把它说成有统计置信度的25分位真值。

主动全部关闭；f06有限寿命、救火/消耗成长Joker整张排除；玻璃实例连点数花色一起移除，作为全破碎压力。随机幸运采用最低分支。Boss在该快速估计器中不模拟，估计结果只能做无Boss基准，不能推断Boss可过；手牌上限实验只支持5–9，永久扩至10–14明确拒绝，不截断掩盖。只出五张也会漏掉某些更优少张打法；英雄续航优势未纳入，不能用它作跨英雄公平标尺。

第13章F资历36、同花Lv5/c06+6，两手预算，26张合成牌组：

| 混色2–A重复 | 1,230 | 720–27,538,337 |
| 全红桃2–A重复 | 56,364,028 | 52,472,884–85,507,317 |

## 消耗、破碎、一次性爆发边界

- **f06**：同一实例连续结算为212/212/212/212/106；第四手仍×2，之后销毁，不能把其峰值延长至下一场能力。
- **救火**：第一次符合资格读×3，afterHand消耗；后手不能无弃牌成本再读；估计器排除整张，宁可漏掉资源收益。
- **燃30＋包场20金阈值**：同配置无燃48,904,084。现金30/39/49燃后0/9/19，包场失效，得108,675,742（约2.22倍）；现金50/60燃后20/30，得195,616,336（恰为未取整前×4）。29不能燃30，再用本场已用技能拒绝。不得把最大×4既当免费常态又保留燃前现金乘区。
- **二响**：交棒每场一次，重复使用被拒；同花葫芦不继承c07“同花/同花顺末张重触发”资格。核算所用玻璃重触发压力改用d11第三张的真实资格，不能靠路线名称想当然。
- **玻璃**：当前每原始有效玻璃牌最终分数后25%破碎；重触发重复×2/版次效果但不重复掷破碎。32个固定seed检查得分相同、确有破与不破、单原始牌只检查一次。这是边界而非频率估计。
- 五张均每手有效计分玻璃：一次全存活(3/4)^5=243/1024≈23.73%，至少一张破碎≈76.27%；若各原始实例都连续使用四次，预期剩5*(3/4)^4=405/256≈1.582张。实际凑型/抽牌也随永久移除变化，不能拿第一手×32乘四当场能力，更不能据爆发后直接涨下一章。
