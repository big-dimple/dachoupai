## 结论与推荐

**推荐最小实现方向是：常规D0和既有局保留；可选择无尽挑战采用外生、共享、关前公布锁定的表，保持现行计分；资历重构只保留为新身份的后续对照。** 无尽挑战可较劲，成熟构筑在普通/暖场稳定超额仍可作为成长回报。选择强度不要求预判G/S/F路线；S/GF/SF只用于分析。正式参数与新菜单均未获本轮实施授权。

已完成六个固定ScoreInput配方、六个章节、三阶段、九种被动策略的**972个状态切片、162个区间**，以及有限供牌/资源解算、外生挑战级别扫描。结果不是自然胜率，也不认证用户旧档。完整保存未取得，先前“实际合法保存的最优可行解”这一证据层仍缺；本轮完成的是明确配方和已声明供牌的离线影子求解，不能偷换为完整保存重放。

严格反例标准“所有普通构筑可过、所有成熟构筑不能稳定首手过”不是用户批准的硬要求。它仅说明统一抬目标有不兼容边界，不是动态追分的依据。本报告另计算允许成熟超额的基础区间，以及仅在主动选择的挑战中要求至少一个压轴压力窗口的区间；不强制每场多手、不要求普通构筑全部通过。

**实际可执行的候选区间已给出：** 第13章，共享挑战曲线×6.1、160,000第8章锚点，在给定成熟GF/SF配方及4/4/3手供牌模型中，预选强度q的可行整数区间为 **[2928,4096]**（扫描上界4096）。q=4096时三目标为 **5,535,146,318,234 / 8,302,719,477,351 / 11,070,292,636,468**。同花顺暖场仍首手超额；GF需2手暖场、3手正场/压轴，SF需1/2/2手。原分数完全保留，没有按这一手得分追涨目标。这只是选定强构筑的区间见证，不能把它强加给用户31.93亿旧手或普通构筑，也不是最终产品参数。

第20章同一冻结Lv5/实例成长配方的GF在正场和快板压轴已不可行，SF仍能过；因此此表不承诺永久续航或“全成熟都能过”。这是公开、可预测的挑战斜率取舍，是否给出更多强度级别、何时进入、目标是否合适，需要有限验证。无可靠自然样本时，不能把六个固定配方的失败占比称为“普通合理失败率”。

### B 削弱/重构被动资历，但保留经营与爆发操作

已扫描C=2/4/8：

- cap-product：每族min(Rf,C)仍叠乘，总界C²。
- cap-max：整手取max(min(Rf,C))，总界C，不再双族叠乘。
- linear-max：每族1+max(N−3,0)×对应首增量，取最大族；例G为1+0.35×max(N−3,0)。这是线性增长实验，不是代码bug修复。

牌型等级、Joker已有经营成长、增强/版次、重触发与英雄主动都在被动因子之外；压缩后它们的相对增益仍保留，但**旧局绝对得分会实质下降**，不能称无代价或“没有惩罚既得成长”。PR144已公布G14同输入历史公式310,793,589，cap-max=4仅剩 **2,912,241**。这未通过自然亿分保护线，故不推荐先部署B，更不能静默迁移旧档。

目标须联合重新定锚：cap-max=4下，第13章普通G/S/F四手最低预算72,800，把它扔进现行暖场12,740,199会直接失去可行解。报告给出一个纯数学重锚见证：含薄G、同时考虑4/4/3手预算，暖场基准2034，q=48的三目标97,632/146,448/195,264。GF/SF在这个主动挑战中可过，暖场仍允许GF首手超额；普通薄G用q=1有供牌路径。2034、4、48都是分析见证，不是产品定参数，更不表示用个体能力实时重算目标。

B适合作为后续新身份/新局的小范围对照，必要条件是同时锁共享目标、保旧档、补有限自然高分与经营窗口验证。不能因数学上存在较劲区间就声称体验合格，也不把这项验证变成18局全部完成的前置。

### C 有上下界、仅关前定值的挑战等级

已实现离线锁定函数：q为明确玩家选择或预先公布的挑战合同值，范围1–4096；T=ceil(公开精确基准×场系数×q)。API拒绝score/inventory/samples/peak等输入，保存policyVersion、章/场、基准有理数、q、精确目标与B14增量。同场恢复读锁定记录，不按实际出牌高低、刷低样本、现金或卖牌变化重新计算；正式玩法没有接入这段函数。

现有D1–D3的目标倍率均×1.2，并另缩减资源；它们不等价本报告的大q扫描，不把新强度直接套到现有档名。

因此成长不会触发自动加难度：在同章同场同q中，目标对买牌、训练、版次和主动的导数为0。它不保证每一章仍容易，但升级收益不会被系统按比例抵消。改变q是公开选择，不能偷偷降低当前已锁定场的门槛；关后更换强度的时点、奖励与记录语义尚未定，本轮没有实现这种菜单或任务系统。

现行×2.4曲线即使q上界4096，也不能给第13章两个成熟配方同时提供压轴压力窗口。更陡共享×6.1曲线出现上文[2928,4096]区间，且允许暖场首手超额。到第20章，同一Lv5配方的GF/SF不存在同时预算可行且有压轴窗口的q区间；这仍不是动态追分的理由。可以容许自然失败、选择不同公开强度、或靠实际经营突破固定切片，不能保证所有强构筑永远续航。

实现最小选择：**先只读接影子表/锁定记录校验；以后若获玩法授权，挑战入口/既有难度选择明确给目标和风险，常规D0仍可选择。** 不让玩家预选未来路线，不以隐藏能力估计发放难度。虚拟挑战者先只复用现有Boss规则类别作评估：资源型B09、来源/顺序型B06/B13、后手型B05/B15；招式与高光必须对应真实规则事件，保留大爆发一击通过。未新增免死盾、强制多手、对手新画像或新的Boss数值。
